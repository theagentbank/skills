# Security

Please do not open a public issue for a vulnerability or include credentials,
private keys, seed phrases, JWTs, Privy tokens, or identity proofs in a report.

Report security issues privately through the security reporting feature of the
GitHub repository. Include a concise impact statement, reproduction steps, and
the affected version or commit.

The MCP bootstrap never replaces an existing conflicting `agentbank`
configuration. Review conflicts locally before making any manual change.
